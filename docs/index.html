Abstract

โปรเจคนี้คือเกมงูกินแอปเปิ้ลที่ทำงานบน Arduino UNO R4 WiFi เพียงบอร์ดเดียว แสดงผลบน LED Matrix 12x8 ในตัวบอร์ด ควบคุมทิศทางด้วย Joystick และปรับความเร็วด้วย Potentiometer เมื่อเกมจบ บอร์ดนับคะแนนเองและส่งผ่าน WiFi ไปเก็บบน Firebase Realtime Database หน้าเว็บบน github.io ดึงคะแนนมาจัดอันดับและแสดง 10 อันดับสูงสุดแบบอัตโนมัติ ผู้เล่นจึงแข่งกันได้ทันทีโดยไม่ต้องกรอกข้อมูลเอง

Input

  • Joystick (A2, A3) อ่านค่าแกน X/Y เพื่อกำหนดทิศทางงู และไม่ให้เลี้ยวกลับหลังหันทันที
  • Potentiometer (A5) ปรับความเร็วเกมแบบต่อเนื่อง

Process

  • สนามเล่น 12x8 พิกเซล งูทะลุขอบไปโผล่อีกฝั่งได้
  • สุ่มตำแหน่งแอปเปิ้ล ตรวจการกินและการชนตัวเอง
  • กินแล้วงูยาวขึ้น 1 ช่อง คะแนนคือความยาวที่เพิ่มขึ้น

Connectivity

บอร์ดเชื่อม WiFi ด้วย library WiFiS3 แล้วส่งคะแนนด้วย HTTPS POST (JSON) ไปยัง Firebase Realtime Database หน้าเว็บดึงข้อมูลด้วย fetch() ทุก 10 วินาที โดย Rules ของฐานข้อมูลรับเฉพาะคะแนน 0-500 และห้ามแก้ข้อมูลเดิม
