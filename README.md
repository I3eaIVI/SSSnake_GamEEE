# SSSnake_GamEEE
นำเสนอ รศ.ดร. ปานวิทย์ ธุวะนุติ อาจารย์ประจำคณะเทคโนโลยีสารสนเทศ สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง
## Overview
### บทคัดย่อ

โปรเจคนี้คือเกมงูกินแอปเปิ้ลที่ทำงานบน Arduino UNO R4 WiFi เพียงบอร์ดเดียว โดยแสดงผลบน LED Matrix ขนาด 12x8 ที่มีในตัวบอร์ด ผู้เล่นควบคุมทิศทางของงูด้วย Joystick และปรับความเร็วของเกมได้ทันทีด้วย Potentiometer เมื่อเกมจบ บอร์ดจะนับคะแนนเองและส่งคะแนนผ่าน WiFi ไปเก็บบน Firebase Realtime Database จากนั้นหน้าเว็บบน github.io จะดึงคะแนนมาจัดอันดับและแสดง 10 อันดับสูงสุดแบบอัตโนมัติ ทำให้ผู้เล่นแข่งขันกันได้โดยไม่ต้องกรอกข้อมูลใดๆ เอง
ที่มาและวัตถุประสงค์
เพื่อศึกษาการเชื่อมต่อระบบ Physical Computing ตั้งแต่ต้นจนจบ ได้แก่ การรับค่าจาก Input (Joystick, Potentiometer) การประมวลผลตรรกะเกมบนไมโครคอนโทรลเลอร์ การแสดงผลบน Output (LED Matrix) และการสื่อสารกับเซิร์ฟเวอร์ผ่านอินเทอร์เน็ต

### หลักการทำงาน

Input: Joystick อ่านค่าแกน X/Y เพื่อกำหนดทิศทางงู (ไม่ให้กลับหลังหันทันที) ส่วน Potentiometer กำหนดความเร็วของเกมแบบต่อเนื่อง

Process: บอร์ดคำนวณตำแหน่งงู สุ่มตำแหน่งแอปเปิ้ล ตรวจการกินและการชนตัวเอง และนับคะแนนจากความยาวที่เพิ่มขึ้น งูเดินทะลุขอบจอไปโผล่อีกฝั่งได้

Output: LED Matrix แสดงตัวงู แอปเปิ้ล (กะพริบ) และข้อความ SNAKE, GAME OVER, SCORE

Network: เมื่อเกมจบ บอร์ดส่งคะแนนด้วย HTTPS POST ไปยัง Firebase

Web: หน้าเว็บอ่านคะแนน เรียงจากมากไปน้อย แสดง 10 อันดับแรก และรีเฟรชอัตโนมัติทุก 10 วินาที

### อุปกรณ์และเครื่องมือ

Arduino UNO R4 WiFi (LED Matrix 12x8 และ WiFi ในตัว)

Joystick module, Potentiometer, Breadboard และสายจัมเปอร์

Arduino IDE, ไลบรารี Arduino_LED_Matrix, ArduinoGraphics, WiFiS3

Firebase Realtime Database, HTML/CSS/JavaScript, GitHub Pages
